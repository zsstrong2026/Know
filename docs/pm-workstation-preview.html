46 大功能模块

① 创建项目

新项目：动态建知识库（复用 CreateKnowledgeBase）+ 建常驻 PM 会话；已存在项目：选择既有知识库。1:1 关联，仅归档不删除。

② 需求池

列表/看板双视图：看板按需求状态分列、拖拽流转。新建需求两步弹窗：表单填基础信息 → AI 分析弹窗，以产品路线图为上下文引导补充详细情况，输出具体设计方案（可二次编辑）+ 价值/影响/风险，确认后生成卡片；另有上线验证回填。

③ 功能规划 持续规划

贯穿全生命周期：首期规划 / 增量规划 / 重新规划 3 种模式，每次规划形成批次记录与快照。AI 引导 5 步（项目认知 → 三级功能清单 → 可视化业务流程 → 首期范围 → 确认生成），左对话右草稿实时同步。路线图视图按批次条切换、可查规划历史与快照，作为需求 AI 分析与 PRD 生成的骨架上下文；确认时可同步功能清单。

④ 功能清单

三级树形（模块→功能点→操作项）；PRD 生成时同步导出结构化数据直接落库；功能点与版本多对多，保留迭代历史（新增/变更/移除），状态按最新迭代版本联动，杜绝手工维护漂移。

⑤ 版本管理

需求归纳（多对多）+ 计划上线日 → 自动生成 PRD+功能清单+原型 → 评审意见按轮次记录并补结论/参会人/意见处理跟踪 → 重生成新版本文档 → 定稿校验结论并生成版本号与更新内容大纲 → 启动开发/上线联动需求状态。

⑥ 项目资料

操作手册/宣传册/PPT 标记版本号；新版本上线提示"有新版可用"，手动确认后重生成草稿→确认替换，旧版归档可回滚。

5AI 技术通道（已探查确认可行）

会话 项目常驻

每项目一个常驻 PM 会话，累积项目背景与评审历史；AI 操作注入 skill_names 触发技能，SSE 流式执行。

技能 自研 5 个

pm-roadmap-planner（5 步引导，输出三级清单 + Mermaid 流程图）/ pm-requirement-analysis / pm-prd-generator（PRD+功能清单双产物）/ pm-prototype / pm-material；规划与分析为交互式引导，其余静默产出、确定性强。

执行 异步任务

复用 doc_assistant 的 asynq 队列，前端轮询进度；"起草→转格式"分步规避沙箱 120s 超时 / ReAct 10 轮上限。

落库 knowledge_id 关联

产物经 CreateKnowledgeFromPassageSync 写入知识库（需求/ 需求/规划历史/ PRD/ 原型/ 资料/，规划历史为需求下的子目录）；pm_* 表记录 knowledge_id+类型+版本号，支撑版本追溯与更新。

6实现分期

一期 · 主链路闭环

项目创建 + 功能规划（持续规划：3 种模式 + 5 步 AI 引导 + 批次与快照） + 需求池（两步弹窗 + AI 分析含设计方案、列表/看板双视图）+ 版本管理（PRD/原型生成、评审迭代、定稿上线）+ 功能清单同步（PRD / 路线图双来源，多对多迭代）

二期 · 上线与复盘

上线验证回填（效果/价值达成/复盘，依赖版本上线数据）

三期 · 交付扩展

项目资料（手册/宣传册/PPT 自动更新）

7风险与约束
风险应对
沙箱 120s 超时 / ReAct 10 轮上限长任务拆"起草→转格式"多步，走异步队列
技能输出格式漂移引导分析强制 JSON 输出；PRD 功能清单章节模板约束 + AI 兜底
资料被 AI 错误内容静默覆盖先草稿后定稿 + 人工确认 + 旧版归档，杜绝静默替换
路线图被直接改写、无快照可回溯不提供独立"编辑"入口，变更统一走规划引导；每次生成写批次快照，历史批次只读
流程图渲染兼容性（Mermaid 语法差异）统一 flowchart 子集，生成后校验语法；同时保存 Mermaid 代码与渲染图，不支持时降级为图片
知识库目录层级能力受限退化为命名前缀约定（REQ-xxx / ROADMAP-HIS-{批次} / PRD-v1.2.0 / …）
技能安装网络受限遵循现有技能安装流程（zip 包上传 / installer agent）

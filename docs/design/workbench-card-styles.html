工作台卡片样式 四套方向

预览

四套方案都保留现有功能（打开、收藏、归档、更多、选择模式），只重排视觉层级。 主要解决截图里的四个问题：封面空洞、信息分散、版本号重复、卡片高度参差。 每一套都可以只改 WorkbenchItemCard.vue 落地。

沿用现有设计令牌 缩略图由 CSS 绘制，无需新增资源 亮 / 暗色同步可看
01封面是 116px 的空网格——一屏十几张卡，同样的网格重复十几遍，只有纹理没有信息。
02信息分散在四行——类型/日期、归档状态、时间、版本各占一行，扫读时视线来回跳。
03版本号重复——已归档时，徽标里的「· v3」和底部「v3」同时出现。
04卡片高度参差——归档按钮出现时正文被顶高，网格行高不齐（截图第一、二行可见）。
推荐 · 平衡

方案 A · 纸页预览

识别强 密度中 改动最小

保留封面，但把空网格换成「一张纸」的缩略：白色纸页 + 标题与正文骨架线；画布显示点阵与节点，数据表显示行列。 封面从装饰变成内容预告。类型、日期合并成一行，时间和归档状态收进底栏，卡片高度统一为 190px 左右。

密度优先

方案 B · 极简紧凑

一屏更多 最安静 成本最低

直接去掉封面：34px 类型图标 + 标题 + 元信息，卡片高度约 106px，同等空间可多看 40% 左右的条目。 类型只靠图标和文字区分，不用颜色，长期使用不疲劳，适合条目上百后的知识库。

第二张卡为悬停态：仅描边加深，不位移，避免密集网格里跳动。

视觉优先

方案 C · 类型色封面

识别最快 需调暗色 新增类型色令牌

封面用低饱和的类型色渐变 + 大号水印图标，文档、画布、数据表一眼可分；卡片无描边、靠柔和投影浮起，圆角 14px。 视觉记忆点最强，但类型色要和品牌绿保持距离，暗色模式需要单独调一组低亮度色。

轻量

方案 D · 无边封面流

最干净 边界感弱 操作靠悬停

去掉卡片盒子，只保留 4:3 圆角封面和两行文字，像浏览图片流；悬停时封面浮起并出现星标与更多。 页面最轻，注意力集中在封面内容上，但条目边界弱，选择模式需要补一层选中描边。

落地建议
  • 首选 A：在现有结构上改动最小，保留封面带来的辨识度，同时解决「空网格 + 信息分散」两个主要问题；高度统一后网格也会变整齐。
  • 条目很多选 B：如果目标是把「最近」当检索入口而不是展示页，B 的密度优势最明显，可以把归档操作收进悬停区。
  • 要记忆点选 C：类型色能让人第一眼分清洗文档、画布和数据表，但需要多一组暗色配色，视觉也更抢。
  • 要呼吸感选 D：最接近内容流，适合以后接入真实缩略图；现阶段纸页骨架已经能撑住空封面，不会显得空。

选好方案后，我按该方向直接修改 WorkbenchItemCard.vue，并同步核对亮 / 暗色与选择模式。

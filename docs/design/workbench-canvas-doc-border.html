无限画布里的文档，默认带一圈边框

现状：切到无限画布后，文档（note 卡片）与画布底色接近，边界感很弱，容易和其他便签糊在一起。 下面 5 套方案都只作用于「文档」本身，画布上新建的便签不受影响；默认态显示边框，悬停加深一级，选中时仍沿用画布原生的蓝色选框。

推荐 方案 B · 卡片浮层：描边 + 低强度投影，缩放到 50% 时边界仍然清晰。
A

发丝线

最克制
67%

一圈 1px 中性灰描边，不加投影。视觉重量最轻，几乎不改变文档原本的气质，适合追求极简的界面。

描边
1px rgba(31,35,41,.16)
圆角 / 投影
10px / 无

适合：极简偏好、大面积画布；注意：缩小到 50% 以下描边会偏淡。

B

卡片浮层

推荐默认
67%

1px 描边 + 一层很轻的投影。描边负责“边界”，投影负责“浮起”，缩放到 50% 时两者仍能互相补位。

描边
1px rgba(31,35,41,.10)
投影
0 16px 36px -20px rgba(16,24,40,.30)
圆角
10px

适合：作为默认态；注意：投影强度要低，避免画布上出现一圈“雾”。

C

双线画框

最有仪式感
67%

外圈 1px，内缩 4px 再压一条 1px 内线，像把文档装进画框。正式感强，适合长文档、对外材料。

外框
1px rgba(31,35,41,.16)
内线
1px，内缩 4px
圆角 / 投影
10px / 无

适合：正式文档、演示场景；注意：内线会压住内边距，正文需要多留 4px。

D

左侧书脊

辨识度最高
67%

普通描边之外，在左侧内衬一条 3px 品牌色书脊，像笔记本的装订边，一眼能看出“这是一份文档”。

描边
1px rgba(31,35,41,.14)
书脊
3px rgba(0,82,217,.55)

适合：文档与便签混排、需要快速区分；注意：带颜色，多个文档并排时会有重复感。

E

虚线草稿

最“画布”
67%

1.5px 虚线边框，弱化“正式纸张”的重量感，更像画布上的一个占位或草稿，和网格背景更协调。

描边
1.5px dashed rgba(31,35,41,.26)
圆角 / 投影
10px / 无

适合：草稿、临时文档；注意：虚线容易被理解为“未完成”或“可拖放占位”。

交互状态

以方案 B 为例：边框只在默认态出现，选中时交还给画布原生选框

实现口径

确认方案后按这些约束落地
  • 作用范围只给无限画布中的「文档根 note」加描边；画布上新建的便签继续沿用设置里的笔记样式，互不影响。
  • 画布缩放边框随缩放变化。为保证 50% 缩放下仍可辨识，推荐「1px 描边 + 低强度投影」组合，而不是单纯加粗描边。
  • 状态优先级默认（描边）→ 悬停（描边加深一级）→ 选中（画布原生蓝色选框，不再叠加自定义描边，避免双框）。
  • 主题适配浅色用低透明度墨色描边；深色翻成低透明度白色描边，投影强度相应减弱，避免发灰。
  • 可配置可复用现有「编辑器 → 笔记样式」里的边框 / 圆角 / 阴影偏好，也可以新增一个「文档边框」预设项，具体听你的。
确认方式：直接回复方案字母即可，例如「选 B」或「B，但边框再淡一点」。颜色深浅、圆角、投影强度、是否可关闭，也可以一起定，我再按最终口径实现到工作台。

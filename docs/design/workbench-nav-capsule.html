Workbench · Navigation Redesign

工作台导航胶囊化设计稿

当前左侧是「全局导航（260px）+ 工作台二级导航（216px）」两条灰色竖向列表，行高、图标与选中态几乎同构， 层级只能靠位置判断，整体视觉偏重。以下三套方案把工作台菜单切换为胶囊语言，信息架构与品牌绿保持不变。

品牌绿 #07C05F 胶囊圆角 999px 沿用 --td-* / --app-* 令牌 含浅色 / 深色两种模式
预览
推荐

方案 A · 胶囊浮岛

信息架构不变 文件夹常驻可见 左侧仍为两条

保留二级导航，把整块栏做成悬浮的圆角卡片，菜单项独立成胶囊。选中项填充品牌绿、白字、带柔和投影， 与全局导航的「浅灰行 + 绿色文字」形成明确对比，两条栏不再看起来像同一组列表。

方案 B · 胶囊顶栏

左侧只剩一条导航 文件夹改浮层 改动范围较大

直接取消工作台的左侧二级导航，把 5 个入口收进内容区顶部的一条胶囊分段栏；文件夹与新建收为右侧胶囊按钮， 文件夹树点开为浮层。左侧只剩全局导航，最彻底地消除“两个导航栏”的重复感。

方案 C · 胶囊滑轨

视觉噪音更低 文件夹常驻 选中块在轨道内滑动

5 个入口共享一条纵向胶囊轨道，未选中项透明、选中项浮起为白色小胶囊并配品牌绿文字。 比方案 A 更克制，绿色只做点睛；侧栏可进一步收窄为 56px 图标条，适合内容优先的场景。

方案对比

方案左侧导航数量文件夹视觉重量改动范围适合
A · 胶囊浮岛2 条常驻，层级缩进中（浮岛 + 绿色选中）WorkbenchNav + FolderTree 样式保留现有信息架构，先解决视觉重复
B · 胶囊顶栏1 条浮层，默认收起低（内容区更开阔）WorkbenchLayout 结构调整 + 新增文件夹浮层明确要“左侧只剩一条栏”
C · 胶囊滑轨2 条常驻，层级缩进低（绿色仅点睛）WorkbenchNav + FolderTree 样式想降噪，同时保留文件夹常驻

设计规格

胶囊尺寸

  • 菜单项38px 高 · 圆角 999px · 左右内边距 12px
  • 图标16px 线性图标，与文字间距 9px
  • 间距胶囊之间 2px，避免“粘连”
  • 文件夹行29px 高，同样胶囊形，保持缩进

状态与色彩

  • 选中#07C05F → #049B38 135° 渐变，白字 + 柔和绿投影
  • 悬停--td-bg-color-container-hover，文字转主色
  • 浮岛圆角 18px、1px 描边、0 18px 44px 低透明阴影
  • 深色选中仍用品牌绿，靠描边与阴影分隔，避免发光过重

代码落点

  • A / C改 [WorkbenchNav.vue] 模板与样式，[FolderTree.vue] 圆角；布局不动
  • B改 [WorkbenchLayout.vue] 结构，移除二级导航，新增顶部胶囊栏与文件夹浮层
  • 文案沿用现有 i18n key，无需新增词条
  • 兜底保留 workbench-buttons.css，现有按钮重置规则继续生效
建议：先按方案 A 实现，改动集中在 WorkbenchNav.vue，不动路由与布局，风险最低；如果目标是“左侧只留一条导航”， 则选方案 B，内容区可多出约 216px 宽度，但需要额外处理文件夹浮层与 Journals 日历入口。方案 C 适合后续做“折叠成图标条”的进阶形态。

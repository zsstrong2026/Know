# PM 项目资料（pm-material）

**确定性技能**：给定最新 PRD、功能清单与资料类型即静默产出草稿，不向用户提问。
服务于「PM 工作站 → 项目资料 → 创建/更新资料」。

## 1. 触发场景

- 用户创建资料并选择类型：操作手册 `manual`、宣传册 `brochure`、PPT `ppt`。
- 新版本上线后，用户点击「更新资料」，基于最新 PRD 重新生成草稿。
- 更新时旧版保留归档，不覆盖删除。

## 2. 输入契约

| 字段 | 说明 |
|---|---|
| `material_type` | `manual` / `brochure` / `ppt`（必填） |
| `target_version` | 资料标记的目标版本号 |
| `prd_markdown` | 目标版本 PRD 全文（必填） |
| `features` | 功能清单三级数据（模块 / 功能点 / 操作项） |
| `project` | 项目名称、简介、目标用户 |

`material_type` 不在枚举内或 `prd_markdown` 为空时，直接返回失败原因，不产出草稿。

## 3. 各类型产出规范

### 3.1 操作手册 `manual`（Markdown）

面向最终用户，按「任务」组织而非按代码模块组织：

```markdown
# {项目名称} 操作手册（{目标版本}）

## 1. 产品简介
- 适用对象、解决的核心问题、版本说明

## 2. 快速开始
- 登录与入口、首次使用必做的 3 件事

## 3. 功能操作
### 3.1 {模块}
#### {功能点}
- 使用场景：
- 操作步骤：
  1. …
- 结果说明：
- 常见问题：

## 4. 常见问题（FAQ）

## 5. 附录
- 术语表、权限说明、版本变更记录
```

- 每个操作项必须能落到至少一条操作步骤，不得只写功能名。
- 术语统一，首次出现给出解释。

### 3.2 宣传册 `brochure`（Markdown）

面向决策者与潜在用户，强调价值而非操作：

```markdown
# {项目名称} 产品介绍

## 一句话价值

## 目标用户与典型场景

## 核心能力
- {能力}：{带来的结果}

## 与同类方案的差异

## 客户收益（量化优先）

## 版本与获取方式
```

- 不出现内部术语、接口名、字段名。
- 每个核心能力 1–2 句，总长控制在 800 字以内。

### 3.3 PPT `ppt`（Markdown 大纲）

按「一页一节」输出，供后续转 pptx：

```markdown
# {项目名称} 演示大纲（{目标版本}）

## Slide 1 封面
- 标题 / 副标题 / 版本 / 日期

## Slide 2 问题与机会
- 3 条以内要点

## Slide 3 产品定位
- …

## Slide 4-N 核心能力
- 每页 1 个能力：标题 + 3 条要点 + 配图建议

## Slide N+1 客户价值

## Slide N+2 版本规划

## Slide N+3 结束页
```

- 每页要点不超过 5 条，每条不超过 25 字。
- 给出「配图建议」而非真实图片，禁止引用外部图片链接。

## 4. 输出契约

- 草稿统一为 **Markdown**（PPT 为大纲 Markdown）；需要富文本时可附单文件 HTML，但必须自包含。
- 输出顺序：先 `title` 建议，再正文草稿，最后变更说明。
- 变更说明（更新场景必填）：

```json
{"change_summary": "基于 v1.2.0 新增「批量导入」章节；更新权限说明；移除已下线功能"}
```

- 不得输出 docx / pptx 二进制；正式格式由调用方在用户确认后转换。

## 5. 更新规则

- 更新只基于**最新已上线版本**的 PRD 与功能清单，不混用历史版本。
- 与旧版对比后，在变更说明中列出新增 / 修改 / 移除章节。
- 旧版归档保留，不覆盖；不主动删除任何已有资料。

## 6. 沙箱能力边界

- **不得联网**：不得抓取图片、模板或外部文案。
- **单次执行不超过 120 秒**：内容过长时按章节分批输出，优先完成核心章节。
- **ReAct 不超过 10 轮**：不做多轮外部校验。
- 只生成草稿文本，不发布、不转格式、不写知识库。

## 7. 失败兜底

| 情况 | 处理 |
|---|---|
| `material_type` 非法 | 返回 `{"error": "不支持的资料类型"}` |
| PRD 为空或缺少功能详述 | 返回 `{"error": "缺少可用的 PRD 内容"}` |
| 功能清单缺失 | 仅按 PRD 第 3 章生成，并在文首标注「未关联功能清单」 |
| 内容超出单次输出上限 | 输出目录 + 已完成章节，并标注「后续章节待生成」 |
| 更新时找不到旧版 | 按新建处理，变更说明写「首次生成」 |
